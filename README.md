# Embedded Sensing & TinyML

A collection of embedded systems projects using the Arduino Nano 33 BLE Sense Rev2, focusing on sensor data acquisition, signal processing, physical modeling, and embedded machine learning.

The projects combine theoretical concepts with practical implementation using Arduino IDE (C/C++) and Python.

## Projects

### 1. IMU-Based Position Estimation

Estimating geographic coordinates (latitude and longitude) without GPS/GNSS, wireless positioning, or additional sensor hardware.

The project explores physics-based localization methods enhanced by machine learning, focusing on estimation accuracy, robustness, and computational constraints.

**[View Project](01-IMU-Based%20Position%20Estimation/README.md)**

### 2. TinyML Gesture Recognition

Developing an embedded gesture recognition system capable of identifying predefined movements or symbols drawn in the air using onboard motion sensors.

The project focuses on sensor data acquisition, signal preprocessing, machine learning model training, and real-time inference directly on the microcontroller.

**[View Project](02-TinyML-Gesture-Recognition/README.md)**

## Hardware & Software

- **Microcontroller:** Arduino Nano 33 BLE Sense Rev2
- **Embedded Development:** Arduino IDE 2 (C/C++)
- **Data Processing & Visualization:** Python
- **Machine Learning:** TensorFlow / PyTorch (depending on implementation)

## Project Status

Both projects are currently under development.
